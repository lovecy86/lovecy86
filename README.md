## 🌟 Featured Projects
- **[Smart Prediction of Mental Health](https://github.com/lovecy86/Smart_Prediction_of_Mental_Health)**: Built a CatBoost model to predict mental health treatment needs, deployed via Flask on AWS EC2. Leveraged Spark and Kaggle data. *(Pinned, End-to-End Workflow)*
- **[Flight Price Analysis and API Integration](https://github.com/lovecy86/Flight-Price-Analysis-and-API-Integration)**: Analyzed one year flight data (from Mrach 2025 till February 2026) for selective airports. The data was cleaned, validated, imported into Postgres and then loaded to the server via Flask. *(Pinned, High Impact)*
- **[Bike Share Analysis](https://github.com/lovecy86/Bike-Share-Analysis)**: Investigated the impact of weather conditions on bike-share usage patterns in Central Chicago. By leveraging historical data and API integrations, uncovered key trends, predicted ridership, and provided actionable insights for urban planning and operational improvements. *(Pinned, High Impact)*
- **[Crowdfunding_ETL](https://github.com/lovecy86/Crowdfunding_ETL)**: Analyzed crowdfunding data and integrated PostgreSQL with Python using Psycopg2. The project involved cleaning, transforming, and storing data in a structured PostgreSQL database, making it accessible for further analysis. *(Pinned, High Impact)*
